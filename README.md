# 요양 근무 수첩 (공개용)

로그인 없이 휴대폰에서 바로 여는 업무 수첩 페이지예요.

- 주소: https://raw.githack.com/trustyoon82-source/trustyoon-cardnews-assets/yoyang/index.html
- 들어 있는 것: 역할별 오늘 순서(3인 MD·2D·3D, 2인 1D·2D, 야간), 알림 시간, 업무매뉴얼 비교표
- 빠진 것: 월별 근무표·행사표, 사진, 동료 이름 (Claude 앱 버전에만 있어요)
- 체크 표시는 각자 휴대폰 브라우저에만 저장돼요.

이 브랜치는 카드뉴스(main, queue/)와 상관없어요. 업로드 자동화에 영향 없음.
