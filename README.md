# 요양 근무 수첩 (공개용)

로그인 없이 휴대폰에서 바로 여는 업무 수첩 페이지예요.

- 주소: https://raw.githack.com/trustyoon82-source/trustyoon-cardnews-assets/yoyang/index.html
- 들어 있는 것: 역할별 오늘 순서(3인 MD·2D·3D, 2인 1D·2D, 야간), 알림 시간, 업무매뉴얼 비교표
- 빠진 것: 근무표·행사표 사진, 동료 이름 (Claude 앱 버전에만 있어요)
- 체크 표시는 각자 휴대폰 브라우저에만 저장돼요.

## 내 근무표

이 저장소에는 근무표가 없어요. 개인 근무표는 링크 끝에 붙여서 본인에게만 보내요.
링크를 한 번 열면 그 휴대폰에 저장되고, 그날 역할이 자동으로 골라져요.

    index.html#s=YYYY-MM.(그 달 날짜 수만큼 한 글자씩)

| 글자 | 근무 |
|---|---|
| M | 3인 MD (조근) |
| A / B | 3인 2D / 3D |
| D | 3인 D (2D·3D 모름) |
| 1 / 2 | 2인 1D / 2D |
| d | 2인 (역할 모름) |
| N / n | 야간 (그날 주간 3명 / 2명) |
| Y | 야간 (인원 모름) |
| x | 휴무 |
| - | 비움 |

이 브랜치는 카드뉴스(main, queue/)와 상관없어요. 업로드 자동화에 영향 없음.
